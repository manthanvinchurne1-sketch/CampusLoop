# CampusLoop

A student-to-student campus marketplace for buying and selling college essentials.

## Technology Stack

- Frontend: React, Vite, and Tailwind CSS (planned)
- Backend: Java 21 and Spring Boot
- Database: PostgreSQL 17
- ORM: Spring Data JPA / Hibernate
- Build: Maven Wrapper
- Payments: Razorpay Test Mode (planned)

## Core Features

- Student registration and authentication
- Product listings and marketplace search
- Selling and managing products
- Shopping cart and checkout
- Order history and order status
- Simulated payment-provider transactions
- Responsive desktop and mobile interface

## Project Status

The initial Spring Boot backend has been generated, and its initial application-context test passes. The remaining application features are under development.
